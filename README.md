# S.O.S. Estudiantil Valparaíso

## Descripción del Proyecto

S.O.S. Estudiantil Valparaíso es una herramienta de orientación que traduce el complejo laberinto normativo a un lenguaje accesible, entregando al estudiantado universitario rutas de acción claras y estructuradas.

Nuestro objetivo principal es orientar a estudiantes universitarios de la Región de Valparaíso ante posibles vulneraciones de derechos o conflictos normativos, mediante un sistema de selección que permita clasificar la situación y entregar una ruta estandarizada de acción, con pasos claros, información sobre los derechos involucrados, normativa aplicable y recursos institucionales.

## Prerequisitos
- Django 6.1.2
- Python 3.13.15
